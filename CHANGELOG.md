# Changelog

## 0.0.2 - 2026-01-07

*   Converted package to pure Dart, removing Flutter dependencies.
*   Externalized doctor notes, allowing custom notes to be provided to `ScareEngine`.
*   Improved localization fallback logic in `ScareQuestion` and `ScareOption`.
*   Added English translations for all questions in `assets/questions.json`.
*   Made `collection` an explicit dependency in `pubspec.yaml`.

## 0.0.1 - 2026-01-07

*   Initial release of `scare_engine`.
*   Includes core logic for psychological profiling and question generation.
*   Supports AI and Redux integration patterns.
